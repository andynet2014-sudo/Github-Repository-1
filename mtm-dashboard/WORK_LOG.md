# 터미널 작업 로그

여러 세션/브랜치를 동시에 오가다 보면 "내가 지금 뭘 하고 있었는지" 헷갈리기 쉽다.
이 파일은 터미널에서 실제로 실행한 작업을 **시간순으로 append**하는 실무 로그다.

- `DECISIONS.md` = 여러 세션에 걸친 굵직한 서사("왜 지금 이 모양인지")
- `CLAUDE.md` = 지켜야 할 규칙
- `WORK_LOG.md`(이 파일) = "언제, 어느 브랜치에서, 뭘 했는지"의 시간순 기록 — 특히
  여러 브랜치를 오갈 때 충돌 안 나게 관리하기 위한 용도

## 쓰는 법

새 작업을 시작하거나 끝낼 때마다 아래 형식으로 맨 아래에 추가한다:

```
### YYYY-MM-DD HH:MM (KST) — 브랜치명
- 한 일 (커밋 해시가 있으면 같이 적기)
- 상태: 진행중 / 완료 / 다른 세션과 충돌 위험 있음 등
```

굵직한 "왜"는 여기 말고 `DECISIONS.md`에 적을 것. 여기는 가볍게, 빠르게 append만.
