# data/raw/ — 증권사 원본 벌크 자료

사용자가 증권사 앱/사이트에서 직접 export한 원본 파일. 수기 대조·재계산의 근거가 되는
1차 자료이므로 가공하지 않고 그대로 보관한다. `data/*.csv`(daily.csv, journal.csv 등,
`collect.py`가 관리)와는 별개이며 여기 있는 파일이 자동으로 그쪽에 반영되지는 않는다.

## data/raw/csv/ — 변환본

`convert_raw.py`로 위 xlsx 3종(거래내역 국장·미장, 일별잔고 미장)을 CSV로 변환한 것.
숫자 컬럼의 콤마(`1,563,000` 등)를 제거해 숫자형으로 정규화한 것 외에는 원본 그대로다.
PDF(`월말잔고현황...`)는 다계좌 피벗 리포트라 자동 변환 신뢰도가 낮아 CSV화하지 않았다 —
필요한 값은 사람이 직접 읽어 `daily.csv`에 반영한다.

갱신 시 원본 xlsx를 이 폴더에 교체한 뒤 `python3 convert_raw.py`를 다시 실행하면 된다.
