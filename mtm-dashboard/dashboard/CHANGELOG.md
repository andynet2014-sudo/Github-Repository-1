# MtM Dashboard (risk-console) — 버전 기록

아티팩트: https://claude.ai/code/artifact/66481dfc-fea9-4c7e-8051-5adf12384a77
소스는 `dashboard/risk-console.html` — 수정 후 같은 URL로 재배포하고, 이 파일에 버전을 한 줄씩 추가한다.
버전업은 요청 시점이 아니라 **실제로 코드 반영 + 재배포까지 끝난 시점**에 한다.

- "실질 누적 순손익"은 우측 breakdown 행으로 이동, (−) 강의·구독비 왼쪽에 배치,
  다른 항목과 같은 폰트 크기 + 연한 초록(.bd-item-real)
- 배포 전 목업(스크린샷)으로 먼저 확인받고 "배포" 확정 후에만 버전 올리는 흐름을
  이번 턴부터 명시적으로 적용

## v1.06 — 2026-08-27
히어로(실질 누적 순손익) 섹션 확장 — 계좌별 기준원금·총평가액·세액·이자를 카드 안에서 바로 확인.
- 국장/미장/ISA 각각 4행: 손익 → 전일比 → 총평가액 → 기준원금(+계좌별 추가행)
  - 국장만 "총평가액(신용차감후)" 표기(신용 있는 계좌는 국장뿐), ISA/미장은 "총평가액"만
  - 국장 하단에 "※ 누적신용이자" 행 추가(상단 breakdown에서는 이 항목 제거)
  - 미장은 세전(surface_pnl) 금액을 메인으로 표시, "세후" 배지 제거, 대신
    "※ 예상세액" 행 추가 — `cum_tax_est`는 올해 실현 해외주식손익(99,059,995원)
    기준으로 갱신: (99,059,995 − 250만) × 22% = 21,243,199원
  - 상단 총계에 "CoB M/D" 라벨 추가, "전일比"에서 날짜 괄호 제거해 간결화
- `data/daily.csv` 8/26 국장 값 보정(+4,777,504원) — 8/26→8/27 dod가 사용자 확인
  실측치(+21,146,061원)와 맞도록, SKT 매매 실현손익 누락분으로 추정해 반영
- 자동수집 파이프라인이 다른 세션에서 이 아티팩트를 stock_charts 없이 재배포한 걸
  발견해서, 배포 직전에 build_stock_charts.py로 복원 후 진행
- journal.csv의 realized_pnl 컬럼이 대부분 비어 있어(5건·137만원) 매매내역 기반
  세액 자동추정은 아직 근거 부족 — 당분간 사용자 확정치를 받아 반영하는 방식 유지
